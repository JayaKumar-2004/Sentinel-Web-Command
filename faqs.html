Frequently Asked Questions

Access classified intelligence and operational directives regarding the Raksha-Suraksha Tactical Command System's architecture, fallbacks, and security protocols.

1. What is the Raksha-Suraksha Command System?
It is an elite bidirectional command-and-control (C2) platform. It allows authorized agents to remotely monitor, track, and secure physical mobile hardware using a secure web interface connected to cloud analytics.
2. How does the Offline SMS Fallback work?
If the target mobile device loses internet connectivity, the web terminal can dispatch encrypted SMS payloads. The companion Android app intercepts these hidden texts and triggers hardware actions (like locking the screen or sounding an alarm) entirely offline.
3. Is my location data secure?
Absolutely. All data transit uses 256-bit TLS encryption. The Firebase Realtime Database is locked behind strict security rules, ensuring only authenticated agents can read or write coordinate streams.
4. What permissions does the Android app require?
To execute advanced tactical operations, the companion app requires Device Administrator rights, background location access, and SMS reception permissions to facilitate the offline bridge.
5. Can a thief just uninstall the app?
No. Because the app is granted Device Administrator privileges during initial setup, it is completely locked into the operating system. It cannot be forcefully uninstalled or force-stopped without entering the agent's Master Passcode.
6. Does continuous GPS tracking drain the battery?
The system utilizes dynamic WAKE_LOCK algorithms. By default, coordinates are fetched efficiently to balance accuracy with power consumption, preserving the hardware's operational lifespan in the field.
7. Can I manage multiple devices from one account?
Yes. The App Linking Bridge allows a single command node (your dashboard account) to authorize and manage telemetry streams from multiple physical devices simultaneously.
8. What is the "Tier-3 Vault"?
The Tier-3 Vault is a restricted-access cloud sector designed to store sensitive evidence records, intercepted audio logs, and high-risk operational data captured from the field hardware.
9. What happens to tracking if the device is powered off?
The web dashboard will immediately log a Connection Terminated status and freeze the map on the last known coordinates WSS ping. The WSS bridge will instantly re-establish the second the hardware boots up.
10. How do I recover a forgotten Master Passcode?
Navigate to the Secure Login portal and click "Forgot Password". Provide your registered Agent Email, and the Firebase WSS server will transmit a secure, time-sensitive override link to your inbox.
11. Do I need to pay for a subscription?
The core framework, including SMS fallback systems and standard WSS telemetry mapping, is accessible without subscription during the initial deployment phase.
12. Which Android versions are supported?
The Raksha-Suraksha tactical client (Sentinel-X) requires Android 8.0 (Oreo) or higher to ensure compatibility with our background service restrictions and WSS bridging protocols.
